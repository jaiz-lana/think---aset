1. Mulai cepat (mode lokal)

Jika Anda hanya ingin mencoba tanpa setup Google:

  1. Buka aplikasi.
  2. Klik Penyimpanan Lokal.
  3. Pilih tema, isi nama organisasi.
  4. Selesai. Data tersimpan di IndexedDB browser Anda.
Mode lokal tidak tersinkron antar perangkat. Backup rutin via Pengaturan → Backup & Restore.

2. Setup Google OAuth Client ID

Dibutuhkan untuk mode Google Drive/Sheets. Gratis, sekali setup.

2.1 Buat project di Google Cloud

  1. Buka Google Cloud Console.
  2. Klik dropdown project → New Project.
  3. Beri nama mis. Think Aset → Create.

2.2 Aktifkan API

  1. Menu → APIs & Services → Library.
  2. Cari dan aktifkan:
    • Google Sheets API
    • Google Drive API
    • Google Picker API (opsional, untuk buka workspace yang dibagikan)

2.3 Konfigurasi OAuth consent screen

  1. Menu → APIs & Services → OAuth consent screen.
  2. User type: External → Create.
  3. Isi App name (mis. Think Aset), User support email, Developer contact.
  4. Di Scopes, tambahkan:
    • https://www.googleapis.com/auth/drive.file
    • https://www.googleapis.com/auth/userinfo.email
    • https://www.googleapis.com/auth/userinfo.profile
  5. Di Test users, tambahkan email Anda (jika mode testing).

2.4 Buat OAuth Client ID

  1. Menu → APIs & Services → Credentials.
  2. Klik Create credentials → OAuth client ID.
  3. Application type: Web application.
  4. Di Authorized JavaScript origins, tambahkan:
    • http://localhost:8080 (untuk testing lokal)
    • https://username.github.io (jika self-host GitHub Pages)
    • Domain produksi Anda yang lain
  5. Authorized redirect URIs tidak perlu diisi (kita pakai token model).
  6. Klik Create → salin Client ID.

2.5 API Key (opsional, untuk Picker)

  1. Di Credentials → Create credentials → API key.
  2. Klik Restrict key → HTTP referrers → masukkan domain Anda.
  3. API restriction → pilih hanya Google Picker API.
  4. Salin API Key.

2.6 Konfigurasi deployment

Pengelola aplikasi menyalin Client ID ke GOOGLE_CLIENT_ID di js/deployment-config.js, lalu deploy ulang. Pengguna tidak perlu membuat Client ID atau API Key sendiri: mereka cukup memilih akun Google dan menyetujui izin.

API Key dan nomor project (App ID) hanya opsional untuk mengaktifkan Google Picker agar pengguna dapat membuka workspace yang sudah dibagikan. Tanpa Picker, pengguna tetap dapat membuat workspace Drive/Sheets miliknya sendiri.

3. Self-host

3.1 GitHub Pages

  1. Fork / clone repo ke akun GitHub Anda.
  2. Buka Settings → Pages.
  3. Source: branch main, folder / (root) → Save.
  4. Buka https://username.github.io/think-aset/.
  5. Ingat: tambahkan origin ini di OAuth Client ID.

3.2 Cloudflare Pages

  1. Login ke Cloudflare Pages → Create project.
  2. Pilih Direct Upload, unggah folder repo.
  3. Selesai. Anda dapat URL HTTPS.
  4. Tambahkan URL tersebut ke Authorized origins di Google Cloud.

3.3 PC sendiri (localhost)

git clone https://github.com/username/think-aset.git
cd think-aset
python3 -m http.server 8080

Buka http://localhost:8080. PWA tetap berfungsi di localhost meski tanpa HTTPS.

4. Penggunaan dasar

  1. Login → pilih mode Google atau lokal.
  2. Onboarding → pilih tema, isi nama organisasi.
  3. Dashboard → ringkasan aset dan grafik. Agenda hanya dapat dilihat bila datanya tersedia.
  4. Data Aset → klik Tambah Aset, isi form, atau impor Excel.
  5. Kategori, Lokasi, Penanggung Jawab → kelola data pendukung aset.
  6. Pengaturan → atur tema, nama organisasi, dan backup lokal.

5. Berbagi dengan anggota tim

Pengelolaan undangan anggota belum tersedia di aplikasi. Jika workspace Google dibagikan langsung melalui Google Drive, anggota dapat login Google lalu memilih Buka workspace yang dibagikan dari layar masuk jika pengelola deployment mengaktifkan Google Picker. Picker memerlukan API Key dan App ID yang disiapkan sekali oleh pengelola, bukan oleh setiap pengguna.

6. Backup & restore

Mode lokal: Pengaturan → Unduh Backup (JSON). Untuk restore: Pengaturan → Pulihkan Backup → pilih file.

Mode Google: data sudah di Spreadsheet Drive Anda. Untuk backup ekstra, buka Google Sheets → File → Download → Microsoft Excel.

7. FAQ teknis

Kenapa butuh API Key untuk Picker?

Google Picker API memerlukan API Key dan App ID yang disiapkan pengelola deployment. Pengguna tidak memerlukannya untuk membuat workspace Google sendiri; operasi data tetap memakai izin OAuth akun pengguna.

Token disimpan di mana?

Hanya di sessionStorage tab aktif. Tertutup tab = hilang. Refresh halaman = login ulang bila token kedaluwarsa.

Bagaimana kalau muncul error 403/429?

Aplikasi otomatis retry bertahap. Jika masih gagal, artinya kuota Google API Anda habis atau permintaan ditolak. Tunggu beberapa menit lalu coba lagi.

Bisakah saya memakai domain sendiri?

Bisa. Host di domain mana pun yang mendukung static hosting (Cloudflare Pages, Netlify, Vercel). Jangan lupa tambahkan origin ke OAuth Client ID.

Apa bedanya dengan aplikasi manajemen aset SaaS?

SaaS menyimpan data Anda di server mereka. Think Aset tidak punya server — data di Drive/browser Anda. Tidak ada langganan, tidak ada vendor lock-in, kode sumber terbuka.

Manajemen aset & inventaris kantor. Open source, MIT, tanpa server.
