Privasi

Kebijakan Privasi

Think Aset tidak mengoperasikan server aplikasi atau analytics. Aplikasi menggunakan layanan Google dan CDN sesuai fitur yang Anda pilih.

Terakhir diperbarui: 2026. Dokumen ini berlaku untuk aplikasi Think Aset dan halaman profil publiknya.

1. Ringkasan

Think Aset adalah aplikasi statis (PWA) yang di-hosting di layanan seperti GitHub Pages, Cloudflare Pages, atau PC Anda sendiri. Aplikasi ini:

  • Tidak memiliki backend — tidak ada server aplikasi milik pengembang.
  • Tidak menyimpan data pengguna di server pengembang.
  • Tidak memakai analytics pihak ketiga (Google Analytics, Meta Pixel, dll).
  • Tidak memakai cookie untuk pelacakan.

Untuk login dan penyimpanan mode Google, aplikasi berkomunikasi langsung dengan Google. Chart.js dan SheetJS dimuat dari CDN saat grafik atau impor/ekspor spreadsheet digunakan. Penyedia layanan tersebut dapat menerima metadata koneksi seperti alamat IP dan permintaan berkas browser; Think Aset tidak mengirimkan data aset kepada CDN.

2. Data yang Anda buat

Data yang Anda masukkan disimpan pada salah satu dari:

  • Google Drive/Sheets Anda (mode Google) — file dibuat di akun Google pribadi/organisasi Anda. Hanya Anda dan pihak yang Anda undang yang dapat mengakses.
  • IndexedDB browser Anda (mode lokal) — data tidak pernah meninggalkan perangkat. Menghapus data situs di browser akan menghapus semua data Think Aset lokal.

3. Scope akses Google

Jika Anda login dengan Google, aplikasi meminta scope:

  • drive.file — hanya file yang dibuat atau dibuka oleh aplikasi ini. Think Aset tidak dapat melihat file lain di Drive Anda.
  • userinfo.email dan userinfo.profile — untuk menampilkan nama & email Anda di UI.

Aplikasi tidak meminta scope lebih dari itu.

4. Token autentikasi

Token Google (access token) disimpan di sessionStorage pada sesi tab browser. Token dikirim hanya ke Google untuk mengakses layanan yang diminta dan tidak dikirim ke pengembang.

5. File yang diunggah

Foto aset dan berkas yang diunggah ditempatkan di:

  • Folder Drive Anda sendiri (mode Google), atau
  • IndexedDB browser (mode lokal).

6. Berbagi dengan anggota

Undangan anggota tersedia untuk pemilik workspace Google. Google memproses alamat email dan izin akses sesuai pengaturan Drive. Think Aset tidak menyimpan daftar email di server pengembang.

7. Log & error

Think Aset tidak mengirim log atau error ke server pengembang. Jika terjadi error, pesan hanya muncul di konsol browser Anda.

8. Hak Anda

Anda dapat:

  • Menghapus Spreadsheet/folder terkait di Google Drive kapan saja.
  • Menghapus data lokal dengan membersihkan data situs di browser.
  • Mencabut akses aplikasi lewat Google Account Permissions.

9. Anak-anak

Think Aset tidak ditujukan untuk anak di bawah usia 13 tahun tanpa pengawasan orang tua.

10. Perubahan kebijakan

Perubahan pada dokumen ini akan disertakan di commit history repositori GitHub. Kami tidak mengumpulkan email untuk mengirim pemberitahuan.

11. Kontak

Untuk pertanyaan tentang privasi, buka issue di GitHub atau lihat halaman kontak.

Dokumen ini bersifat informatif, bukan nasihat hukum. Jika Anda meng-host Think Aset untuk organisasi dengan kebutuhan kepatuhan khusus, konsultasikan dengan tim hukum Anda.
