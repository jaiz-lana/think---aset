Kenapa pakai Think Aset?

Empat masalah yang paling sering dihadapi pengelola aset — dan bagaimana Think Aset menyelesaikannya.

01 · Mendata

Mendata aset dalam hitungan menit

Buat daftar aset lengkap dengan foto, kategori, lokasi, penanggung jawab, dan nilai. Impor dari Excel/CSV sekaligus, atau tambah satu per satu.

Kode aset bisa otomatis dengan format yang Anda tentukan (mis. INV/KANTOR/2025/0001).

Roadmap · Memantau

Memantau perpindahan & penanggung jawab

Riwayat perpindahan dan perubahan kondisi per aset belum tersedia pada versi saat ini. Informasi lokasi dan penanggung jawab dapat dicatat pada data aset.

Timeline perubahan aset direncanakan untuk tahap pengembangan berikutnya.

03 · Menghitung

Hitung penyusutan otomatis

Metode garis lurus atau saldo menurun digunakan untuk menghitung beban bulanan, akumulasi penyusutan, dan nilai buku aset.

Jadwal penyusutan lengkap dan ekspor laporan penyusutan belum tersedia.

Roadmap · QR

Cegah aset hilang dengan QR

Pembuatan QR, pencetakan label, dan pemindaian kamera belum tersedia pada versi saat ini. Fitur tersebut direncanakan untuk tahap pengembangan berikutnya.

Kartu aset siap cetak juga masih termasuk roadmap.

Apa itu Think Aset?

Aplikasi web open source (PWA) untuk mendata, memantau, dan menyusutkan aset. Berjalan di browser — tidak perlu install server, tidak perlu langganan.

1

Pilih penyimpanan

Pilih akun Google untuk menyimpan di Drive/Sheets tanpa membuat API Key, atau gunakan Penyimpanan Lokal tanpa akun.

2

Catat aset

Isi form, impor Excel/CSV, atau tempel foto. Kategori, lokasi, penanggung jawab lengkap.

3

Pantau data

Kelola aset, kategori, lokasi, dan penanggung jawab; lihat ringkasan serta grafik di dashboard.

Data tersimpan di penyimpanan Anda sendiri. Kami tidak menyimpan apa pun di server.

Data Milik Anda

Think Aset tidak punya backend. Semua data hidup di akun Google Anda atau di perangkat yang Anda pakai. Kami tidak pernah melihat, apalagi menyimpan.

  • Tidak ada analytics pihak ketiga.
  • Tidak ada langganan, tidak ada iklan.
  • Kode sumber terbuka — diaudit siapa saja.
  • Lisensi MIT — boleh dimodifikasi & didistribusikan.
  • Bisa di-self-host: GitHub Pages, Cloudflare, atau PC sendiri.

Pertanyaan umum

Jawaban singkat untuk pertanyaan yang sering muncul.

Apakah data saya aman?

Anda memilih mode penyimpanan saat membuka aplikasi. Mode Google memakai akun Anda sendiri (scope drive.file): aplikasi hanya bisa mengakses file yang dibuat/dibuka oleh aplikasi ini. Mode lokal menyimpan data di IndexedDB browser Anda. Pengembang tidak memiliki akses ke data siapa pun.

Apa bedanya Google Drive dan Penyimpanan Lokal?

Google Drive: data berada di Spreadsheet Anda. Pengelola aplikasi menyiapkan koneksi Google sekali untuk semua pengguna. Buka workspace yang sama lewat Picker pada perangkat lain untuk mengakses data yang sama. Lokal: data di browser saja, tidak tersinkron, cocok untuk personal atau uji coba tanpa akun.

Apakah berbayar?

Tidak. Think Aset gratis selamanya dengan lisensi MIT. Anda hanya perlu akun Google gratis bila memilih mode Google Drive. Anda cukup memilih akun dan menyetujui izin aplikasi; API Key hanya diperlukan pengelola bila mengaktifkan Google Picker.

Bisa dipakai offline?

Setelah halaman dimuat sekali, aplikasi bekerja offline berkat service worker. Mode lokal berjalan 100% offline; mode Google butuh koneksi untuk sinkronisasi.

Bagaimana cara install di HP?

Buka aplikasi di Chrome/Safari HP, lalu pilih menu Install app atau Tambahkan ke layar utama. Ikon Think Aset akan muncul seperti aplikasi biasa.

Bagaimana cara menambah anggota tim?

Undangan anggota melalui aplikasi belum tersedia. Untuk saat ini, pemilik workspace dapat mengatur akses langsung dari Google Drive; anggota dapat memilih workspace melalui Picker jika pengelola deployment mengaktifkannya.

Bisakah saya menghapus semua data saya?

Tentu. Mode Google: hapus Spreadsheet & folder di Drive Anda. Mode Lokal: klik Keluar dan bersihkan data situs di browser Anda. Aplikasi tidak menyimpan salinan apa pun.

Siap menata aset kantor Anda?

Mulai sekarang — tanpa registrasi server, tanpa biaya, tanpa komitmen.
